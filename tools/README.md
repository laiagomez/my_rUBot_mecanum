# Tools

This directory contains scripts, configuration and installation material used
to prepare, configure or maintain a rUBot. They are not ROS 2 runtime packages.

| Directory | Purpose |
| --- | --- |
| `humble_network/` | ROS 2 Humble network and Docker configuration. |
| `robot_installation/` | Robot installation, services, camera and Arduino resources. |
| `web_dashboard/` | Static web dashboard served through Rosbridge. |
| `yolo_model_generation/` | Dataset preparation, YOLO training and local inference tools. |

See the README or Markdown files inside each directory for its specific
instructions.
